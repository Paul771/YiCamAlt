Rules (02-RESEARCH.md Pattern 6, VERIFIED-LOCAL + PUBLIC):
- Decrypt only I-frames, only when p2pEncrypt; payload.size >= 36 required; blocks [4,20) and [20,36) decrypted independently; key = (password + "0") US-ASCII; key length not 16/24/32 → leave as is, return false.
- NAL type: H.264 `b & 0x1F` (SPS 7, PPS 8, IDR 5); H.265 `(b >> 1) & 0x3F` (VPS 32, SPS 33, PPS 34, IDR 19/20, CRA 21).
- Assembler: I-frame resets the decode point and is emitted; P emitted only if seq == last+1 (u16 wrap); future P buffered (cap 100, drop oldest); P with seq <= last dropped; P before first I dropped; current generation = useCount of the latest I-frame, P with another useCount dropped.
