From plan 02-00 (`com.yicamalt.stream.StreamTypes.kt`): `data class FrameInfo(codecId, flags, liveFlag, onlineNum, useCount, seq, width, height, timestampSec: Long, isDay, cover, outLoss, inLoss, timestampMs: Long) { isKeyFrame }`.

Byte layouts (02-RESEARCH.md Pattern 4, VERIFIED-LOCAL; TNP big-endian):
```
TNPHead (8):        [0] version (send 2) [1] ioType (1 video, 2 audio, 3 command) [2] abilityRet (rx) [3] reserved [4..8) u32 dataSize
TNPIOCtrlHead (40): [0..2) u16 commandType [2..4) u16 commandNumber (starts at 1, ++ per command)
                    [4..6) u16 exHeaderSize (0) [6..8) u16 payloadSize
                    tx: [8..40) authInfo 32 B ASCII zero-padded;  rx: [8..12) s32 authResult (0 ok; 1|2 wrong password; 4 retry)
Command unit:       TNPHead(version, 3, 40 + payload.size) + IOCtrlHead + payload
FrameHead (24):     [0..2) u16 codec_id [2] flags (bit0 I) [3] liveFlag [4] onlineNum [5] useCount [6..8) u16 seq
                    [8..10) u16 width [10..12) u16 height [12..16) u32 timestamp s [16] isDay [17] cover [18] outloss [19] inloss
                    [20..24) u32 timestamp_ms
Max dataSize per channel: ch0 cmd 204800, ch1 audio 5120, ch2/ch6 I 1048576 (ch6 new-live: use 1048576), ch3 P 307200; 0 < size required.
Payloads: 4881 SET_RESOLUTION 8 B = u32 BE resolution + u32 BE useCount; 9029 TNP_START_REALTIME 4 B = [useCount, resolution, 1, 0];
          768 AUDIOSTART 8 zero bytes; 767 STOP 8 zero bytes; TUTK start: 8190 (encrypted) / 511 (plain) = u32 LE useCount.
Replies:  4882 → authResult at IOCtrl offset 8; 9033 (kick) → u32 reason in payload (1 → APP_KICK_MAX_SESSION -3101, else APP_KICKED -3100).
authInfo: encrypted: nonce = prefix7 + random8 (alphabet A-Z a-z 0-9); pass15 = Base64(HmacSHA1(key=UTF8(pwd), msg=UTF8("user=xiaoyiuser&nonce="+nonce))).take(15);
          text = nonce + "," + pass15 (31 ASCII) zero-padded to 32. Not encrypted: "admin," + pwd (truncate to 32).
```
Code sketches in 02-RESEARCH.md "Code Examples" (YiP2pAuth, TnpCodec.commandUnit) are the starting point.
