`@Composable fun LiveViewScreen(deviceId: String, title: String, onClose: () -> Unit, viewModel: LiveViewModel = hiltViewModel())`. Structure (all blocks paired, names as listed):

2. State: `var requestedFullscreen by remember { mutableStateOf(false) }`, `val landscape = LocalConfiguration.current.orientation == ORIENTATION_LANDSCAPE`, `val fullscreen = ZoomMath.isFullscreen(landscape, requestedFullscreen)`, `var zoom by remember { mutableStateOf(Zoom()) }`, `var controlsVisible`, `var boxSize` (IntSize from `onSizeChanged`), `val textureRef = remember { mutableStateOf<TextureView?>(null) }`.
3. `BLOCK_FULLSCREEN`: `LaunchedEffect(fullscreen)`: `WindowCompat.getInsetsController(window, view).apply { systemBarsBehavior = BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE; if (fullscreen) hide(WindowInsetsCompat.Type.systemBars()) else show(WindowInsetsCompat.Type.systemBars()) }`; button "На весь экран" -> `requestedFullscreen = true; activity.requestedOrientation = SCREEN_ORIENTATION_SENSOR_LANDSCAPE`; exit (button "Свернуть" or back) -> `requestedFullscreen = false; activity.requestedOrientation = SCREEN_ORIENTATION_PORTRAIT`, then an `OrientationEventListener` (remembered, enabled only while waiting) sets `SCREEN_ORIENTATION_UNSPECIFIED` once the sensor reports portrait (angle within 0..30 or 330..359) and disables itself (Pitfall 9). In fullscreen, controls auto-hide after `ZoomMath.CONTROLS_AUTO_HIDE_MS` (LaunchedEffect keyed on controlsVisible); portrait keeps them visible.
4. `BackHandler`: fullscreen -> exit fullscreen; else `onClose()` (closeScreen runs in onDispose).
5. Layout - ONE composition tree whose video slot never moves between branches (Pitfall 8): outer `Surface(color = if (fullscreen) Color.Black else Color.White, contentColor = ...)` -> `Column` (portrait: title row + video box + controls/info below; fullscreen: only the video box with `fillMaxSize()`; the title/info items are wrapped in `if (!fullscreen)` while the video `Box` call stays in the same position of the Column). Video box modifier: `if (fullscreen) Modifier.fillMaxSize() else Modifier.fillMaxWidth().aspectRatio(ui.videoAspect ?: 16f / 9f)`, `.background(Color.Black).clipToBounds().onSizeChanged { boxSize = it }`.
6. `BLOCK_RENDER_VIDEO_SURFACE`: inside the box `AndroidView(factory = { TextureView(it).apply { surfaceTextureListener = object : TextureView.SurfaceTextureListener { onSurfaceTextureAvailable(st, w, h) { viewModel.attachSurface(Surface(st)) }; onSurfaceTextureSizeChanged(...) = Unit; onSurfaceTextureDestroyed(st): Boolean { viewModel.detachSurface(); return true }; onSurfaceTextureUpdated(st) = Unit }; textureRef.value = this } }, update = { it.keepScreenOn = ui.videoRendering }, modifier = Modifier.fillMaxSize().graphicsLayer { scaleX = zoom.scale; scaleY = zoom.scale; translationX = zoom.tx; translationY = zoom.ty })`. No `setZOrderOnTop` (TextureView).
7. Gesture overlay: transparent `Box(Modifier.matchParentSize().pointerInput(boxSize) { detectTransformGestures { _, pan, zoomChange, _ -> zoom = ZoomMath.applyGesture(zoom, zoomChange, pan.x, pan.y, boxSize.width.toFloat(), boxSize.height.toFloat()) } }.pointerInput(boxSize, ui.videoAspect) { detectTapGestures(onTap = { controlsVisible = !controlsVisible }, onDoubleTap = { zoom = ZoomMath.doubleTap(zoom, fill) }) })` where `fill = ZoomMath.fillScale(boxW, boxH, videoW, videoH)` from `ui.videoAspect` (videoW/H derived as aspect*1000 x 1000 when only the aspect is known). Reset zoom to `Zoom()` when `fullscreen` changes.
8. Overlays inside the box (drawn over the TextureView): badge chip top-start (`ui.badge.text`, color by tone: GOOD green, WARN amber, ERROR red, NEUTRAL gray; tap -> `viewModel.toggleDebug()`); when `ui.debugExpanded` a monospace `Text(ui.debugLine)` under it; when `controlsVisible || !fullscreen` a bottom control row: sound `IconButton` (only if `ui.soundVisible`; icon VolumeOff when muted, VolumeUp otherwise; `toggleMute`), quality `TextButton(ui.qualityLabel ?: "")` (only if `ui.qualityVisible`, disabled while `ui.qualityPending`; `toggleQuality`), snapshot `IconButton` (PhotoCamera), fullscreen toggle (Fullscreen / FullscreenExit). If `ui.showRetry` a centered "Повторить" button (`retry`); if `ui.showConnect` a centered "Подключить" button (`connect`); `ui.message` as text under the video in portrait.
9. `BLOCK_SNAPSHOT_CAPTURE` (main thread): on snapshot tap: if `Build.VERSION.SDK_INT < 29` and permission not granted -> `rememberLauncherForActivityResult(RequestPermission())` launch `WRITE_EXTERNAL_STORAGE`; on grant capture. Capture: `val tv = textureRef.value; val bmp = if (ui.videoRendering && tv != null && tv.isAvailable) tv.getBitmap(videoW, videoH) else null` with videoW/videoH from the decoded size (`ui.videoAspect` + the TextureView height, or tv.width/height fallback) - graphicsLayer zoom does not affect getBitmap, so the frame is full and unzoomed; `viewModel.saveSnapshot(bmp)`.
10. Material icons: use `androidx.compose.material.icons.Icons.Filled.*` that already compile in the project (check `grep -rn "Icons.Filled" app/src/main/java` for the extended-icons availability; if `VolumeOff`/`PhotoCamera`/`Fullscreen` are unavailable, use text buttons "Звук"/"Без звука", "Снимок", "Во весь экран" instead - no new dependency).
