```kotlin
sealed interface AudioOutStatus {
    object Idle : AudioOutStatus
    data class Playing(val sampleRate: Int, val channels: Int, val codecName: String) : AudioOutStatus
    data class Failed(val reason: String) : AudioOutStatus      // reason = exception simple name or "no-decoder"
}
class AacDecoder(private val queueCapacity: Int = AudioFrameQueue.DEFAULT_CAPACITY) : AacFrameSink {
    val status: StateFlow<AudioOutStatus>
    override fun onAacFrame(config: AacConfig, frame: ByteArray, ptsUs: Long)   // non-blocking: queue.offer + post pump
    fun release()                                                               // idempotent, bounded (<= 1 s wait)
}
```
Rules:
- Lazy HandlerThread "media-audio" on the first frame; after `release()` every call is a no-op.
- Codec created on the first frame and re-created when `config` differs from the current one: `MediaFormat.createAudioFormat("audio/mp4a-latm", config.sampleRate, config.channels)`, `setByteBuffer("csd-0", ByteBuffer.wrap(config.csd0))`, `setInteger(MediaFormat.KEY_IS_ADTS, 0)`; `MediaCodec.createDecoderByType("audio/mp4a-latm")`; async callback set BEFORE `configure(format, null, null, 0)`, then `start()`. Failure -> status Failed(e.javaClass.simpleName), log `BLOCK_AUDIO_DECODER_CREATE result=failed error=<class>`, frames dropped from then on (no retry loop).
- Input: `onInputBufferAvailable` stores the index; pump writes queued frames (`queueInputBuffer(index, 0, size, ptsUs, 0)`).
- Output: `onOutputFormatChanged` (re)creates `AudioTrack` via `AudioTrack.Builder()` with `AudioAttributes.USAGE_MEDIA` / `CONTENT_TYPE_SPEECH`, `AudioFormat.ENCODING_PCM_16BIT`, sample rate = `KEY_SAMPLE_RATE`, channel mask `CHANNEL_OUT_MONO` (1) or `CHANNEL_OUT_STEREO` (2) from `KEY_CHANNEL_COUNT`, buffer = `max(AudioTrack.getMinBufferSize(...), rate * channels * 2 / 4)` (~250 ms), `TRANSFER_MODE_STREAM`, then `play()`; status Playing; log `BLOCK_AUDIO_TRACK rate=%d ch=%d`. `onOutputBufferAvailable`: `track.write(buffer, info.size, AudioTrack.WRITE_NON_BLOCKING)` then `releaseOutputBuffer(index, false)`; output before a track exists is released without writing.
- `onError` -> release codec + track, status Failed("codec").
- `release()`: on the thread: stop/release codec and track, `quitSafely()`; log `BLOCK_AUDIO_RELEASE dropped=<queue.dropped>`; caller waits at most 1 s (CountDownLatch) like VideoDecoder.runOnDecoder.
