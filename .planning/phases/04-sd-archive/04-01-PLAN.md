Byte layouts (research §P1-P5, all VERIFIED):
- STimeDay 8 B: u16 year (transport order), month, day, wday (java.util.Calendar: Sunday = 1 .. Saturday = 7 = `dayOfWeek.value % 7 + 1`), hour, minute, second.
- listEventsRequest: [0..4) u32 channel 0, [4..12) start with second forced 0, [12..20) end with second forced 0, [20] event 0, [21] status 0, [22..24) 0.
- tnpPlayRecord: [0] useCount low byte, [1] resolution, [2] 1, [3] 0, [4..12) STimeDay BE.
- playControl: [0..4) channel 0, [4..8) command, [8..12) param 0, [12..20) STimeDay or 8 zero bytes when at == null, [20] useCount low byte, [21..24) 0.
- parseTnpIndex: u16 BE count at 0; [2..12) reserved; if size < 12 + count*12 -> emptyList() (vendor treats as zero entries); entry i at 12 + 12*i = STimeDay BE + s32 BE duration.
- parseTutkIndexPage (LE): [0..4) channel, [4..8) s32 total, [8] index, [9] endflag (1 = last), [10] count u8, [11] reserved; accept only when `p.size >= 12 && p.size / 12 - 1 == count` else null; entry = STimeDay LE + [8] event + [9] status + [10..12) u16 LE duration.
- parseDeviceInfo: [0] interface_version, [2] tfstat, [8] hardware_version, isUtc = p[9] when hardware_version != 1 else p[14]; [40..44) s32 total, [44..48) s32 free in transport order; all bytes read unsigned.
- SdTime.toWire uses `Instant.ofEpochMilli(ms).atZone(wireZone)`; fromWire = `LocalDateTime.of(...).atZone(wireZone).toInstant().toEpochMilli()`; dayBounds via `day.atStartOfDay(zone)` and `day.plusDays(1).atStartOfDay(zone)` (never + 86_400_000).

Cases (test names in backticks; fixtures from SdFixtures builders, synthetic dates):

- `tnpPlayRecord bytes`: useCount 3, resolution 1, at 2026-10-30T12:00:00Z -> `03 01 01 00 07 EA 0A 1E 06 0C 00 00`; useCount 259 -> first byte 0x03.
