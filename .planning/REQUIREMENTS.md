# Requirements: YiCamAlt

**Defined:** 2026-10-10
**Core Value:** Открыть приложение → увидеть свои камеры → смотреть живое видео с любой из них, из любой сети, без подписки.

## v1 Requirements

### Security & Hygiene

- [x] **SEC-01**: Логи приложения никогда не содержат hmac, токенов, паролей камер, P2P-лицензий, InitString, DID/p2pid, nonce и серийников — проверяется расширенным `RedactionScanner` на реалистичных фикстурах
- [x] **SEC-02**: Диагностический лог пишется во внутреннее хранилище приложения (не в MTP-доступный external storage)
- [x] **SEC-03**: Вендорские бинарники (APK, .so), декомпилированный код и flow-файлы захвата не попадают в Git — `.gitignore` и проверка перед коммитом
- [x] **SEC-04**: P2P-реквизиты камер хранятся только в памяти / EncryptedSharedPreferences, не в открытом Room

### Camera List

- [ ] **CAM-01**: Пользователь после логина видит список своих камер (собственных и расшаренных ему) с названием, моделью и статусом онлайн/офлайн
- [x] **CAM-02**: Приложение находит камеры независимо от региона аккаунта (gw-us / gw-eu / gw-sg) без ручного ввода URL сервера
- [x] **CAM-03**: Для каждой камеры приложение получает P2P-реквизиты (p2pid/DID, тип транспорта, пароль, InitString, лицензионный ключ) и определяет транспорт (TNP / TUTK)
- [x] **CAM-04**: Если камер нет или запрос не удался, пользователь видит понятное состояние («нет камер» / «ошибка сервера» / «повторить»), а не пустой экран
- [x] **CAM-05**: Список обновляется pull-to-refresh и кэшируется для мгновенного показа при запуске

### Live View

- [ ] **LIVE-01**: Пользователь открывает камеру и видит живое видео в той же Wi-Fi сети, что и камера
- [ ] **LIVE-02**: Пользователь видит живое видео из другой сети (мобильный интернет) — через P2P или relay
- [ ] **LIVE-03**: Поддерживаются камеры с H.264 и H.265
- [ ] **LIVE-04**: Пользователь видит состояние соединения (подключение / LAN / P2P / relay / офлайн / ошибка авторизации)
- [ ] **LIVE-05**: При обрыве сети поток автоматически переподключается без действий пользователя (с ограниченным backoff)
- [ ] **LIVE-06**: Пользователь включает/выключает звук (по умолчанию выключен)
- [ ] **LIVE-07**: Пользователь переключает качество HD/SD (SD по умолчанию на relay)
- [ ] **LIVE-08**: Пользователь сохраняет снимок кадра в галерею
- [ ] **LIVE-09**: Пользователь разворачивает видео на весь экран и масштабирует жестом
- [ ] **LIVE-10**: Поток останавливается при уходе с экрана / сворачивании приложения; одна P2P-сессия на камеру, официальное приложение не блокируется
- [ ] **LIVE-11**: Просмотр не ограничен по времени и без рекламы

### SD Archive

- [ ] **SD-01**: Пользователь выбирает день и видит, за какие дни есть записи на SD-карте
- [ ] **SD-02**: Пользователь видит 24-часовую шкалу с записанными отрезками выбранного дня
- [ ] **SD-03**: Пользователь запускает воспроизведение с выбранного момента и перематывает по шкале
- [ ] **SD-04**: Пользователь ставит паузу, продолжает и возвращается к живому видео
- [ ] **SD-05**: Пользователь видит понятное состояние, если SD-карты нет или записей за день нет

### Events

- [ ] **EVT-01**: Пользователь видит ленту событий движения по всем камерам с превью-картинкой и временем
- [ ] **EVT-02**: Пользователь фильтрует события по камере и по дню
- [ ] **EVT-03**: Пользователь открывает короткий клип события (6 с из облака, бесплатный)
- [ ] **EVT-04**: Пользователь из события переходит к полной записи на SD-карте в момент события
- [ ] **EVT-05**: Ранее загруженные события доступны офлайн из локального кэша
- [ ] **EVT-06**: Опрос событий не чаще раза в 5 минут на переднем плане (безопасно для аккаунта)

### Release

- [ ] **REL-01**: Собирается подписанный APK (arm64-v8a / armeabi-v7a), вендорские .so извлекаются из локального APK при сборке
- [ ] **REL-02**: Все v1-сценарии проверены на реальном телефоне пользователя: LAN, удалённо, при открытом официальном приложении

## v2 Requirements

### Notifications
- **NOTF-01**: Фоновые уведомления о движении (WorkManager, опрос ≥15 мин)

### Live View+
- **LIVE-12**: Двусторонняя связь (микрофон)
- **LIVE-13**: Сетка из нескольких камер
- **LIVE-14**: Picture-in-Picture

### Archive+
- **SD-06**: События с SD-карты как второй источник ленты
- **SD-07**: Скачивание клипа (ремукс в MP4)
- **SD-08**: Скорость воспроизведения

### Control
- **CTRL-01**: PTZ для Dome-камер
- **CTRL-02**: Настройки камеры (вкл/выкл, ночной режим) — деструктивные команды только с подтверждением

### Transport
- **P2P-01**: TUTK-адаптер — только если у пользователя появятся камеры type 0

## Out of Scope

| Feature | Reason |
|---------|--------|
| Платные облачные записи Yi / обход paywall облака | Цель — работать без подписки, не взламывать платные услуги; риск бана |
| Эндпоинты оплаты/подписок (`/orderpay/*`, `/vas/*/cloud/*`, trial) | Анти-фича, риск для аккаунта |
| `/v5/alert/push_prop` и push через Firebase Yi | Ломает уведомления официального приложения |
| yi-hack / RTSP | Пользователь выбрал заводскую прошивку + P2P |
| Добавление/провижнинг новых камер | Делается один раз в официальном приложении |
| Langtao-транспорт (type 1) | Редкие старые модели, нет у пользователя (проверить пробой) |
| iOS / десктоп | Только Android |
| Эмулятор как среда проверки | Нет VT-x и прав администратора; только физический телефон |
